# Jay & Milee Wedding Invitation

Responsive scroll-based wedding invitation.

## Edit content
Update `js/config.js` to change names, dates, event timings, venue, family names, RSVP contacts, music path and theme colours.

The opening/invitation layouts are in `index.html`; visual styling is in `css/styles.css`; interactions are in `js/script.js`.

## Assets
- `assets/caricatures/sangeet.jpg`
- `assets/caricatures/wedding.png` (transparent canvas trimmed and edge pixels cleaned)
- Add your Gujarati instrumental MP3 at `assets/music/gujarati-instrumental.mp3`.

## Run and publish
Open `index.html` in a browser or serve the folder with a local static server. Upload the entire `wedding-invitation` folder to static hosting, preserving the folder structure.
